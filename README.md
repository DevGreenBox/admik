# Admik

**Admik** — универсальная админ-панель для интернет-магазинов.

Проектируется как переиспользуемая платформа (CMS/ERP для сети магазинов), а не
решение под один магазин. Подключение нового магазина — это **настройка и
конфигурирование**, а не переписывание кода.

## Модель «1 магазин = 1 БД»

Каждый интернет-магазин = отдельная БД + отдельная конфигурация, на отдельном
VPS. Кодовая база едина и не меняется между магазинами. Меняются только:

- **конфигурация** (`.env` + таблица настроек) — реквизиты, ключи интеграций,
  включённые модули, брендинг;
- **содержимое БД** — каталог, контент, настройки конкретного магазина.

Данные магазинов физически изолированы. Подробнее — в
[`docs/02-модель-развёртывания.md`](docs/02-модель-развёртывания.md).

## Стек

| Слой | Технология |
|------|-----------|
| Рантайм | Node 20+ |
| Фреймворк | Next.js 16 (App Router, `output: 'standalone'`) |
| UI | React 19 + Tailwind CSS |
| Язык | TypeScript (strict) |
| БД | PostgreSQL 15+ через postgres.js |
| Валидация | Zod |
| Тесты | Vitest |
| Пакетный менеджер | pnpm |

Архитектурные решения зафиксированы в
[`docs/01-архитектурные-решения.md`](docs/01-архитектурные-решения.md).

## Установка

Требуется Node 20+ и pnpm 9+.

```bash
pnpm install
cp .env.example .env   # заполните значения под свой магазин
```

## Запуск

```bash
pnpm dev      # режим разработки (http://localhost:3000)
pnpm build    # production-сборка (standalone)
pnpm start    # запуск production-сборки
```

Проверка готовности: `GET /api/health` → `{ "status": "ok", ... }`.

## Проверки качества

```bash
pnpm typecheck   # tsc --noEmit, без ошибок типов
pnpm test        # vitest run, все тесты зелёные
pnpm test:watch  # vitest в watch-режиме
pnpm lint        # eslint (next/core-web-vitals)
```

Принцип проекта: **сначала тесты, потом код** (см. ADR-004).

## Структура проекта

```
app/            — Next.js App Router (страницы, layout, API-роуты)
features/       — бизнес-модули (каталог, заказы, СДЭК, CMS — будущие этапы)
lib/            — общие библиотеки и утилиты
  config/       — конфигурация: env (Zod) и система модулей
db/migrations/  — идемпотентные SQL-миграции
scripts/        — служебные скрипты (init-shop и т.п.)
config/         — конфигурационные файлы
tests/          — Vitest-тесты
docs/           — проектная документация
```
