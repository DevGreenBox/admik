СТАТУС нового этапа правок (2026-06-17, подробности — docs/00 «Завершённые задачи»):
- Нет возможности удалить товар — ✅ кнопка «Удалить навсегда» в карточке товара
  (action deleteProduct; каскадно удаляет варианты/фото/остатки, история заказов
  сохраняется; коммит 8fe5aeb).
- Не загружает фото товара — ✅ причина: Next.js резал тело Server Action на 1 МБ,
  реальные фото 2–5 МБ молча падали. Поднят bodySizeLimit до 12 МБ (коммит 7b937a4).
  Напоминание: фото грузится во вкладке «Медиа» ПОСЛЕ создания товара (нужен id товара).
- Фото обрезается → вмещать целиком — ✅ витрина THE CASE: миниатюры галереи и
  фото в корзине переведены на object-contain (главное фото PDP и карточка каталога
  уже были contain). Дефолт LuxuryImageSwap НЕ трогали — там home-hero (cover намеренно).
- Не выбрать размер / добавить в корзину + «Халат, остаток 50, но нет в наличии» —
  ✅ один корень для товара БЕЗ размеров: витрина заказывает по productId, но карточка
  Storefront API не отдавала id товара → кнопка показывала «Нет в наличии» при остатке.
  Теперь ProductDetailDto отдаёт product.id (коммит 6809dc3); витрина уже умеет это
  потреблять (checkout/adapter). Доп.: на витрине, если у товара ЕСТЬ размеры и все они
  не в наличии — кнопка честно пишет «Нет в наличии» вместо «Выберите размер».
