## С чего начать новому разработчику

Порядок чтения, восстанавливающий контекст проекта за один заход:

1. **`CLAUDE.md`** (корень репозитория) — правила проекта: мультиагентность, универсальность,
   мультитенантность, TDD, обязательный инструментарий.
2. **`docs/00-журнал-проекта.md`** — история запросов, решений и изменений; список текущих,
   завершённых и отложенных задач. Ведёт History Manager.
3. **`docs/01-архитектурные-решения.md`** — ADR: почему сделано именно так (ADR-001…ADR-021).
4. **`docs/02-модель-развёртывания.md`** — «один магазин = одна БД = один конфиг» + **эксплуатационные
   инварианты** (порядок выкатки Caddy, кеши, CDN). Читать до первой выкатки на прод.
5. **`docs/16-стек-технологий.md`** — из чего собран проект.
6. **`docs/10-состояние-и-продолжение.md`** — снимок состояния и гайд продолжения работ.

## Где искать частые темы

| Вопрос | Где ответ |
|---|---|
| Как подключить новый магазин без правок кода | `02`, ADR-003 в `01` |
| Какие есть роли и права | `04` (RBAC) |
| Структура БД, миграции | `04`, `05`, `07`, `11` (по модулям); правило аддитивности — `02` + ADR-015 |
| Контракт публичного API витрины | `13`, `11 §5.4.4` |
| Настройки магазина (`shop_settings`) | `11 §5.4`, ADR-013 |
| Размерные сетки | `11 §5.4.8` (модель), `13 §3.7` (витрина), `14 §10` (владельцу) |
| Цвет как вариант, свотчи, матрица | `05 §2.4` и `§4.4`, `13 §3.6`, `14 §9` |
| Порядок выкатки Caddy, доверенный IP | `02` «Эксплуатационные инварианты», ADR-020, `09`, `12 §6.4` |
| Почему оплата падает без ключей Т-Банка | `15 §2.1`, ADR-021 |
| Прямой SQL не виден на витрине | `02` (п.3 инвариантов), ADR-019, `09` |
| Пустая секция характеристик обнулила данные | `05 §4.5` («Мина в данных»), `14 §11` |
| Модули: включить/выключить | `11 §5.4` (`module_overrides`), `19` (скилл `module-toggle`) |
