- Вес/габариты товара для расчёта СДЭК — ✅ форма товара («Дополнительно») + у каждого варианта;
  снимок в позиции заказа (миграции 0018/0026), используется в расчёте/создании отправления.
- Накладная только после оплаты — ✅ сервис создаёт отправление лишь при оплате
  (isOrderPaidForShipment); в карточке заказа кнопка «Создать отправление» появляется только после
  поступления оплаты, до этого — пояснение про автосоздание после оплаты (коммит 56622dc).
- Количество товара — ✅ остаток задаётся в админке (вкладка «Варианты» → блок «Остатки»,
  InventorySection): на уровне товара без вариантов и для каждого варианта.
